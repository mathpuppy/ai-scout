## 本线研判

本周（10-12～10-16）agent 论文有三条主线。一是「System One / 决策原生模型」成为新的 agent 架构组件：Jeva（NUS）、VideoJev（南大）、MJev-Spatial 三篇高赞论文把「做决定」从自回归文本生成里拆出来，改为单次前向直接输出结构化决策，充当 LLM「System Two」的快速行动层，配套的 JevAgentHarness、DecisionRobust、Reading Right Acting Wrong 佐证这一范式正在进入 agent loop。二是 computer-use / GUI agent 训练走向开源全栈 + 合成环境规模化：阿里 Tongyi-MAI 连出 OpenGCUA、MAI-Gym，腾讯出 Player-1，上交出 SoftwareGym，主线是把 harness、合成环境、在线 RL 打通。三是 harness 级递归自我改进（RSI）成为核心议题：Google 的 Harness^2（repo ⭐1444）与中关村学院/中科大的 Self-Evolving Agent Harness（PAC 泛化界）都在固定权重下让 harness 自演化，正合本线追踪主题。评测侧整体转向「最后一公里」：AgentSWE 检验交付 agent 是否忠实于需求，FDE-Gym（机构未核，弃）测交付落地。供合流段：System One 决策模型、harness-RSI、computer-use 开源栈三选题热度高，其中 Harness^2 的 repo 与潮流线可对上。
