## 本线研判
本周 Agent 相关条目仍占绝对多数（17 条中 13 条涉 agent），但重心从"再做一个 harness"转向**围绕 harness 的基础设施与标准件**。第一簇是"指挥层"：t3code 以 +17.1k 把控制面从移动端扩成四端，claude-mem 做跨 harness 记忆，worktrunk 做并行 agent 的 worktree 隔离——三者都在回答"多个 agent、多个入口、多台机器时人怎么管"。第二簇是"标准层"：anthropics/skills（规范+官方实现）、github/spec-kit（SDD 流程）、obra/superpowers（跨 20+ harness 的方法论）同周上榜，说明 skills/spec 正在从各家私有格式收敛为可迁移的流程资产。第三簇是"应用层新形态"：OpenMausBot 把多 agent 装进聊天客户端、每个 bot 配云 VM，pr-agent 则代表审查类 agent 的持续存在。值得注意的是单用途"设计品味"skill（impeccable / hallmark / jakubkrehel）本周合计吸走近 1.6 万星，热度很高但内容为提示词资产，按本线口径不计入架构级入选，仅作为"skill 内容包泛滥"的信号记录。清单式 agent 工具（agent-browser）仍是能力层最容易走热的形态。
