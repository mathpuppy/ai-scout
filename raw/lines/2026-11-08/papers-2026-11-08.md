## 事实条目

- **Advances in Agentic Computer Graphics**（University of Texas at Austin〔模型判读〕· arXiv:2611.01860 · upvotes 143）— 为 "LLM agent 写图形学代码并迭代精修" 这一新范式建立统一分类体系与文献系统，梳理人机协作与长程规划的开放问题。 *纳入理由：本周热度第一，agent 作为"代码生成 + 反馈迭代"引擎在专业领域的综述级定型*（[paper](https://huggingface.co/papers/2611.01860)〔repo: 未附〕）

- **CoworkOS: Scaling Agent Coworkers for Real-world Automation**（Renmin University of China · arXiv:2611.03178 · upvotes 100）— 面向长程生产力工作的通用 harness：把任务策略与执行管理解耦，用共享工件支撑人在回路协作，并靠持续自动化后训练稳定提升模型。 *纳入理由：把 "cowork agent" 从单次任务推到可交付长程工作，harness 设计与数据飞轮一并给出*（[paper](https://huggingface.co/papers/2611.03178)〔repo: RUC-NLPIR/CoworkOS ⭐141〕）

- **From Autonomous Agents to Cognitive Symbionts: Toward AI-Augmented Human Intelligence**（University of Oxford · arXiv:2611.05376 · upvotes 86）— 立场论文：主张 agent 的下一步不是更强的自主性，而是共享人的情境、历史与记忆的"认知共生体"，增强而非替代人的判断。 *纳入理由：为 agent 设计目标换轴（autonomy → symbiosis），与本周 harness 线形成价值取向对照*（[paper](https://huggingface.co/papers/2611.05376)〔repo: 未附〕）

- **Route Anything: A Study of Model and Policy Routing for General-Purpose AI Systems**（National University of Singapore〔模型判读〕· arXiv:2611.05275 · upvotes 79）— 在异构专家模型 / 工具 / 策略池上做质量-成本路由的通用研究，学习式路由器在 16 个 benchmark 上稳定优于手工规则，平均效率提升 8.82×。 *纳入理由：把"能力编排"落成可学的路由策略，是 agent 层选模型/选工具的通用组件*（[paper](https://huggingface.co/papers/2611.05275)〔repo: InfRec-Cardinal/route-anything ⭐18〕）

- **Video Generation Meets Agent Harness: Agentic Video Generation, Agentic World Modeling and Recursive Self-Improvement**（Video Rebirth〔模型判读〕· arXiv:2610.40191 · upvotes 78）— 用 agent harness（构建上下文、暴露工具、维护状态、路由反馈、管理预算）包住视频模型，同时充当视频世界模型的交互运行时，并把递归自我改进接入生成流程。 *纳入理由：harness 概念外溢到生成式媒体的标志性报告，跨"生成 / 世界模型 / agent"三域*（[paper](https://huggingface.co/papers/2610.40191)〔repo: agentic-videogen/awesome-agentic-videogen ⭐57〕）

- **Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training**（Shanghai JiaoTong University · arXiv:2611.04277 · upvotes 63）— 观察到 harness 演化具有局部性、互补性与非平稳性，于是让同源的"兄弟 harness"选择性接管基础 harness 的失败 rollout，再把能力蒸馏回单一策略，保持换 harness 后仍有效。 *纳入理由：首个把"harness 组合"当作训练信号的方法论，直击 agent 训练对 harness 过拟合*（[paper](https://huggingface.co/papers/2611.04277)〔repo: DeepExperience/Harness-S ⭐57〕）

- **FrontierPhysics: Evaluating Agents for End-to-End Physics Research**（BenchFlow〔模型判读〕· arXiv:2611.06910 · upvotes 56）— 42 位物理学家按自己研究出 56 个端到端任务（理论/计算/实验九域），要求 agent 走完文献综述到验证全过程，并用确定性验证器 + 专家 rubric 同时查正确性与研究质量。 *纳入理由：agent 科研能力评测从"答题"升级为"做研究"，专家自建任务是稀缺资产*（[paper](https://huggingface.co/papers/2611.06910)〔repo: 未附〕）

- **Axion 1.0: Open Agent Foundation Models, Simplified**（ByteDance〔repo 归属核验〕· arXiv:2611.03233 · upvotes 48）— 完全开源的 agent 基座模型，训练只走 "两阶段 SFT + RL" 三步，明确不做 mid-training / DPO / on-policy distillation，用 model-aware 数据构造补上推理强度。 *纳入理由：agent 基座训练配方的极简化路线，与本周 "harness 决定能力" 的主张互为注脚*（[paper](https://huggingface.co/papers/2611.03233)〔repo: bytedance/axion1_0 ⭐61〕）

- **R²Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop**（Chinese University of Hong Kong, Shenzhen · arXiv:2610.22740 · upvotes 48）— 编排器训练不再依赖手工课程：内循环自选任务自博弈、外循环把技能内化并做技能退出，缓解同结果 rollout 的优势塌陷与单点评测噪声。 *纳入理由：多智能体编排的"自进化"训练范式，与 Harness-S 同属 agent 训练去手工化潮流*（[paper](https://huggingface.co/papers/2610.22740)〔repo: beita6969/R2Orch ⭐48〕）

- **CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements**（Beijing University of Posts and Telecommunications〔模型判读〕· arXiv:2611.03126 · upvotes 46）— 嵌套双环递归改进：外层以"世界-数据模型飞轮"扩展开放交互语料，内层用快照回滚重试与视觉-语义双路轨迹重建提数据质量，OSWorld Verified 达 80.2。 *纳入理由：computer-use agent 的规模化数据配方，本周 CUA 系列里榜单成绩最硬的一篇*（[paper](https://huggingface.co/papers/2611.03126)〔repo: xlyu0106/CUA-Master ⭐124〕）

- **IdeaTaste: Do LLMs Share the Research Taste of Human Researchers?**（Carnegie Mellon University · arXiv:2611.03424 · upvotes 46）— 以 2025 年文献快照为条件让模型写研究提案，再用 2026 年真实发表打分，结果 AI agent 在"大方向"上与人选题一致，但在具体方法与成功预期上明显落后。 *纳入理由：把"研究品味"变成可量化短板，为科研 agent 的能力缺口给出定位*（[paper](https://huggingface.co/papers/2611.03424)〔repo: cxcscmu/IdeaTaste ⭐27〕）

## 本线研判

本周 agent 论文的主轴几乎被 "harness / runtime" 占满：CoworkOS 把长程工作的策略与执行解耦，Harness-S 把 harness 组合当训练信号，Video Rebirth 把 harness 概念搬到视频与世界模型，CUA-Master 则在数据侧配套递归数据飞轮——即"能力上限由包在模型外面的执行系统决定"已从工程经验沉淀为研究对象，且开始被当作可训练、可蒸馏、可自我改进的部件。第二条线是 agent 训练去手工化：R²Orch 用自博弈替代手工课程，Axion 1.0 把 agent 基座配方压到 SFT+RL 三步。第三条线是评测口径上移：FrontierPhysics 要求跑完整个科研流程、IdeaTaste 用未来真实发表校验"研究品味"，与上周偏交互层/工具层的评测形成层次递进。值得注意的两处偏移：Route Anything 说明"编排"正在从 agent 内部下沉为模型/策略路由这一独立研究问题；Oxford 的认知共生体则是唯一对 "更强自主性" 提出反向价值主张的立场论文。GitHub 侧信号：CoworkOS（⭐141）、CUA-Master（⭐124）为本周开源头部件，可作为潮流线交叉核对的锚点。
