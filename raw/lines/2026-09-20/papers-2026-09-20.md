## 本线研判

本周 agent 论文的主线高度集中：**递归自我改进（RSI）成谱系化爆发**——从基座层（Atria Dawn 的可验证经验管线）到世界模型驱动的探索自改进（Dream-RSI），到 harness 层模块化/规模化 RSI（ModularRSI、SoL-Pi），再到免训练的环境自适应（RSIAgent），覆盖训练与推理两端；其中 harness 层 RSI 与 coding agent 组件实证（176 组消融的 Harness Design）正对本仓库 harness 追踪线，说明"harness 即研究对象"已从工程博客进入论文议程。第二梯队是 agent 评测与可信（XConf 经验置信度、ProgramDistill 回放验证基准），开始补长程自主性的可靠性缺口。开源联动信号强：SoL-Pi ⭐2421、Dream-RSI ⭐863、Atria ⭐506、RSIAgent ⭐356，建议合流段与潮流线（GitHub 周榜）对撞核验，同名上榜即为多线点名。
