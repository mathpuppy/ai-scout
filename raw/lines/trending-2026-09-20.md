## 本线研判

本周榜单结构较上期明显换血：上期主角是 skills 单品（i-have-adhd +16.7k 登顶、archify、ponytail、diagram-design 扎堆），本周 skills 品类整体退潮（i-have-adhd -67%、humanizer 微退、hyperframes -51%），archify / ponytail / superpowers / spec-kit 等上期常客全部掉出榜单，印证"skill 即内容"是短周期热度而非稳态赛道。接棒的是三条更重的线：一是 alibaba/open-code-review 以 7 倍周增爆发登顶，确定性规则 + LLM Agent 的混合架构在企业代码评审垂直打出规模样本；二是并行 agent 基建共振走强，新面孔 stablyai/orca（agent fleet 的 ADE + 订阅复用）与 worktrunk 翻倍（worktree 工程配套）、firstmate（crew 编排）同向，multi-agent 并行开发的外围工具层正在成形；三是官方分发层双入口同榜，anthropics/knowledge-work-plugins 新上榜与 openai/plugins 续榜对读，两大厂都在把 skills/plugins 当作 harness 能力面的官方出口经营。另外 addyosmani/agent-skills（97k 总星）与 Agent-Reach（83.5k）两个 2026 年新建仓的量级说明这条赛道的基础设施项目起量速度已到"月级十万星"时代。
