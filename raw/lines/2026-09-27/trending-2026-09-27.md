## 本线研判

上期研判确认的两条曲线本周继续兑现：其一，skill 单品热度继续退潮（i-have-adhd、humanizer、hyperframes、context-mode 全部掉榜），但 skill 品类没有消失而是"工程化 + 官方化"——cloudflare/security-audit-skill 以多阶段流水线 + 机器可读可验证 findings 的新上榜登至第二，addyosmani/agent-skills 与 ECC 续榜，skill 从"内容品"转向"工程品"的分化已经明朗；其二，重架构能力层接棒，本周全榜第一是 vectorize-io/hindsight 的学习型记忆，加上新上榜的 treg（工具路由 OpenRouter 化），memory 与 tool-route 两个 harness 能力面组件同时拿到周榜头部席位，说明"单 agent harness 之战"的外围正在沉淀为独立基建赛道。并行编排线进入稳态：orca 两连涨（+20%）续走强，paperclip 以 87k 总星把 fleet 治理从编排器推到组织管理平面（审批 / 审计 / 团队维度）。官方生态方面 Anthropic 三仓同榜（claude-code + knowledge-work-plugins + financial-services），从通用 harness → 知识工作者插件 → 垂直行业包三层铺开，官方分发渠道的颗粒度在变细。最后一个新叙事值得标记：univer 老牌文档引擎整体重定位为 "Office Harness for AI Agents"，与 CLI-Anything（存量 CLI 软件 agent 化）同向——"把存量软件改造成 agent 运行时"可能成为下一阶段主题，与"造新 harness"形成路线分岔。
