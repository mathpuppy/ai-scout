## 本线研判

本周 agent 论文的最大母题是 **harness 本身成为优化对象**：最高分 RRSI（206）让冻结权重的 agent 递归改写自己的 harness，北大的 Harness-Zero 则反向把 harness 增益蒸馏进模型，一增一减两条路线同时上榜，说明社区正从"训模型"转向"训外壳"。第二条主线是 **agent RL 环境的程序化合成**：CodeMidas 从代码自身造 coding RL 环境、Qwen 的 RecreationWorld 造混合 CUA 环境、阿里按类别迭代训 SWE 专家，共同回应训练环境稀缺这一规模化瓶颈。第三条是 **过程性知识的程序化沉淀**：EvoOntology 的自演化本体、Code2Skill 从代码抽取技能、Just-in-Time Memory 的用时策展，知识来源从轨迹经验扩展到代码/本体/流量。评测侧则向长程决策质量深化（Tasteful Agent 的"品味"、GameHorizon 的多视野）。联动信号：google-research/rrsi（⭐353）、TencentARC/GameHorizon（⭐270）、ruc-datalab/EvoOntology（⭐420）、ant-intl/Code2Skill、QwenLM/RecreationWorld、alibaba/AgenticBigBang 均可与本周期潮流线 GitHub 周榜对表。
