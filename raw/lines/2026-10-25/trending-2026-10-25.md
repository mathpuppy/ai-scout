## 本线研判
本周官方周榜呈「agent 技能与插件生态爆发」：14 条里 12 条与 agent 直接相关。最大方向是「agent skills/plugins 标准化」——Cloudflare 安全审计 skill、Anthropic 官方插件目录 + knowledge-work 插件、Google Android skills 同周上榜，大厂正把 agent 能力打包成可复用、可审计的 skill 单元；第二方向是「agent 运行/控制层」——orca（fleet + 自有订阅）、t3code（移动控制面）、ruflo（多 agent swarm harness）、opencode（开源 coding agent）构成 harness 层的新竞争；记忆（ai-memory）与知识图谱（graphify）代表「给 agent 装长期记忆/结构化知识」的第三方向。ComfyUI、vLLM 这类纯图像/纯推理基础设施在本榜退居边缘，本周热度由 agent 应用层主导。
